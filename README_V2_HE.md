# מסע הניקוד – גרסת לוחות וחיילים

הגרסה כוללת:

- חמישה לוחות משחק אמיתיים: קמץ ופתח, שורוק וקובוץ, חולם חסר ומלא, סגול וצירה, סולמות ונחשים.
- מסך בחירת לוח עם תצוגה מקדימה של כל לוח.
- בחירת 2–6 שחקנים.
- שישה חיילים מאוירים לבחירה, ללא אפשרות לבחור חייל שכבר נבחר.
- הצגת הלוח שנבחר בתוך סצנת המשחק.
- תנועה ידנית: לאחר זריקת הקובייה השחקן גורר את החייל למשבצת המוארת, צעד אחר צעד.
- מניעת דילוג על משבצות והחזרת החייל למקומו אם נגרר למקום שגוי.
- המשך שילוב מערכת השאלות, הניקוד וחלון הניצחון מהגרסה הקודמת.

## הפעלה

```bash
npm install
npm run dev
```

## בדיקה

קוד TypeScript נבדק בהצלחה באמצעות:

```bash
tsc --noEmit
```

הערה: מיקומי המסלול מותאמים לתמונות הלוחות באמצעות קואורדינטות יחסיות. ניתן לדייק כל משבצת בהמשך לפי בדיקת תצוגה בפועל.
