# מסע לחשבון

משחק לימודי להכנה לכיתה א׳ ולתרגול חיבור וחיסור עד 10.

## הפעלה לבדיקה

פתחו PowerShell בתיקיית הפרויקט והריצו:

```powershell
npm install
npm run qa
npm run desktop
```

## יצירת מתקין Windows

```powershell
npm run dist:win
```

המתקין יופיע בתיקייה `release`.

## מבנה המשחק

- חמישה לוחות לימוד בני 30 משבצות.
- לוח מסכם בן 60 משבצות עם ארבעה סולמות וארבעה נחשים.
- בחירת הלוח נעשית רק דרך „משחק חדש”.
- על הלוחות מוצגים מספרי משבצות; התרגיל נפתח לאחר נחיתה.
- עד ארבעה שחקנים, ניסיון שני בשאלה, צלילים, הפחתת תנועה ומסך סיכום.

## בדיקת הפצה

```powershell
npm run release:check
```

אין להריץ `npm audit fix --force` לפני בדיקת תאימות, משום שהוא עלול לשדרג תלויות בשינויים שוברים.
