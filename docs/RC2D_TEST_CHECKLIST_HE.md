# צ'קליסט בדיקה — RC2-D

## תפריט ראשי
- [ ] חמשת הכפתורים מוצגים ללא חפיפה.
- [ ] משחק חדש פותח בחירת שחקנים.
- [ ] בחירת לוח פותחת את ספריית הלוחות.
- [ ] הגדרות נפתח וחוזר לתפריט.
- [ ] אודות נפתח ונסגר.
- [ ] יציאה סוגרת את גרסת Windows לאחר אישור.

## זרימת משחק
- [ ] ניתן להתחיל עם 1, 2, 3 ו־4 שחקנים.
- [ ] שמות השחקנים מוצגים כ"שחקן 1" וכן הלאה.
- [ ] סיום משחק פותח מסך ניצחון.
- [ ] משחק חדש לאחר ניצחון מתחיל ממצב נקי.

## רזולוציות
- [ ] 1366×768.
- [ ] 1920×1080.
- [ ] מסך מלא ויציאה ממסך מלא.
