# מערכת הלוחות — RC2-B

שכבות הלוח מסודרות כך:

1. רקע גרפי 1920×1080 — אווירה בלבד.
2. מסלול מחושב מתוך ה־manifest.
3. סולמות ונחשים המחושבים מתוך `transitions`.
4. משבצות מחושבות מתוך `path`.
5. חיילים הממוקמים באמצעות `anchor`.

הרקע אינו מקור אמת למשחקיות. כל המיקומים, המעברים וקבוצות השאלות מגיעים מקובצי JSON, ולכן ניתן לכייל או לעצב לוח בלי לשנות את מנוע המשחק.
