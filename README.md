# מסע לחשבון

גרסה מאושרת: **v1.2.2**

משחק לימודי להכנה לכיתה א׳ ולתרגול חשבון בסיסי.

## סטטוס
הגרסה נבדקה אצל המשתמש ואושרה כגרסת העבודה האחרונה. עקרון העיצוב המאושר נשמר: תמונת הלוח היא הלוח עצמו, וה־hotspots האינטראקטיביים שקופים לחלוטין.

## תיקון מרכזי ב־v1.2.2
- תוקנה התקלה שבה הלוח לא הופיע לאחר מעבר ל־Hotspots שקופים.
- אין שכבת מסלול או משבצות נוספת מעל האיור.
- נוסף fallback לתמונת התצוגה אם texture של הלוח אינו נטען.
- הלוגו, הסתברות הקובייה והודעת ההנחיה נשמרו.

## פיתוח והרצה
```bash
npm install
npm run dev
```

בדיקות זמינות בפרויקט דרך סקריפטי `npm run qa`, `npm run check` ו־`npm run release:check`.

## גיבוי מקור
חבילת המקור המלאה של הגרסה המאושרת נשמרת לצורך שחזור והמשך עבודה.
